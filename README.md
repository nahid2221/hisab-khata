# হিসাব খাতা

Mobile-first, local-storage based bookkeeping app for small businesses.

## Features
- Dashboard with daily and overall summary
- Fast sales entry with automatic cost, profit and stock deduction
- Same product can be sold at different prices in separate transactions
- Product/stock management
- Product detail + sales history
- Expense tracking
- Reports with product-wise sales/profit and net profit
- Business money calculation excluding stock value from cash
- Local Storage persistence; no backend required
- Responsive desktop sidebar + mobile bottom navigation

## Run
Open `index.html` in a browser. No build step or server is required.

## GitHub Pages
Upload `index.html`, `style.css`, `app.js`, and `README.md` to a repository and enable GitHub Pages from the repository settings.

## Data
Data is stored in the browser's Local Storage under `hisab-khata-v1`. Clearing browser site data will remove it. Firebase/login/cloud backup can be added later.
